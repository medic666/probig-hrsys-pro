# ProBig — 企业人事与行政管理系统

面向中小企业的轻量生产级人事与行政管理系统，以**事件驱动+多层投影**为核心架构，支持人员、公司、考勤、假期、薪资、文件、审计全流程管理。核心服务单文件部署，零外部依赖。

## 技术栈

| 层 | 技术 |
|---|------|
| 后端 | Go + Gin + GORM + SQLite（纯 Go 驱动，无需 CGO） |
| 前端 | Vue 3 + TypeScript + Vite + Element Plus + Pinia |
| 部署 | Go embed 嵌入前端产物，生成单文件可执行程序 |

## 快速开始（开发模式）

```bash
# 1. 启动后端
go run ./cmd/               # 监听 :8080，首次启动自动初始化数据库和管理员账号

# 2. 启动前端 dev server（新终端）
cd web
bun install
bun run dev                 # 监听 :5173，API 请求自动代理到 8080
```

打开浏览器访问 `http://localhost:5173`，使用 `admin / admin123` 登录，首次登录需修改密码。

## 生产构建

```bash
# 方式一：构建脚本（推荐）
bash build.sh

# 方式二：手动构建
cd web && bun run build      # 前端产物输出到 web/dist/
cd ..
cp -r web/dist cmd/dist       # 复制到 Go embed 目录
CGO_ENABLED=0 go build -ldflags="-s -w" -o probig ./cmd/
```

产物为单文件 `probig`（约 27MB，全静态链接），运行：

```bash
GIN_MODE=release ./probig    # 默认监听 :8080
```

## 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `SERVER_PORT` | `8080` | 服务端口 |
| `DB_PATH` | `./hr.db` | SQLite 数据库文件路径 |
| `JWT_SECRET` | `probig-secret-key-change-in-production` | JWT 签名密钥 |
| `FILE_STORAGE_PATH` | `./upload` | 文件上传存储目录 |

## 核心设计理念

### 事件驱动 + 多层投影

```
事件源层（第0层）  →  职务事件、考勤事件、假期账户事件、工资事件
       ↓               原始事实，仅追加+软删除，唯一真相源
基础投影层（第1层） →  职务时段快照、日考勤记工时、假期余额投影
       ↓               由事件自动投影，粒度最细，可全量重建
业务核算层（第2层） →  月度假勤工资
       ↓               手动触发，基于基础投影
结果汇总层（第3层） →  月度工资总表
                       跨模块聚合，全链路可追溯
```

**铁律**：上层只读取下层，绝不反向修改。结果变动需从源事件改起逐层重算。

### 全局软删除

所有业务表默认开启软删除，无「彻底删除」功能。删除数据可通过回收站恢复。

### 审计全覆盖

所有写操作全程留痕，审计日志仅追加不可删除，操作前后数据快照完整记录。

### RBAC 权限

模块级权限粒度（读/写/删/导出/核算），前端后端双重校验。默认超级管理员 `admin`，首次登录强制修改密码。

## 各模块业务功能

### 人员管理
- 基础信息增删查改、搜索筛选、Excel 导出
- 电话号码、邮箱、银行卡独立管理（一对多，加密存储）
- 身份证号全局唯一校验
- 回收站恢复

### 公司管理
- 公司信息增删查改、统一社会信用代码唯一校验
- 银行账号加密存储、文件附件关联
- Excel 导出、回收站恢复

### 职务管理
- 职务事件录入（入职、调薪、转正、离职等），采用「复选框驱动动态表单」
- 增删改事件后自动全量重建职务时段快照
- 快照时段连续不重叠，支持离职后重新入职

### 考勤管理
- 考勤事件：单条/跨天/批量录入，支持出勤、休假、加班、违纪四类
- 日记工时：由考勤事件自动投影，不可手动修改
- 月度假勤工资：基于日工时+职务快照加权核算
- 年假/调休事件自动联动假期余额

### 假期账户
- 额度事件：年假配发、人工调整、系统结转
- 实时余额查询，可下钻明细（累计配发/已休/调整/结转）
- 周年结转：批量操作+反结账，支持负余额滚存

### 工资管理
- 工资事件：绩效系数、提成、奖惩、个税扣除等
- 月度工资汇总：聚合假勤工资+职务标准+假期折算+工资事件
- 全链路追溯：从工资汇总逐层下钻至原始事件

### 文件管理
- 统一文件上传/下载，大小限制可通过系统配置调整
- 文件与业务对象多对多关联
- 删除仅软删除元数据，磁盘文件保留

### 审计日志
- 全量操作日志查询与导出
- 仅支持查询/导出，无修改/删除接口

### 用户与权限
- 用户管理：新增、角色分配、启用/禁用、重置密码
- 角色管理：自定义角色、权限分配
- 超级管理员角色不可删除、不可修改权限

### 系统配置
- 键值对全局配置，修改即时生效
- 涵盖分页条数、导出上限、文件大小、考勤系数、年假额度等
- 加密密钥为只读项
